Fundamentos Previos

Antes de lanzarte a escribir fórmulas, domina el vocabulario y la sintaxis de Excel. Estos 8 conceptos te ahorrarán horas de errores.

Anatomía de una función

⏱️ 15 min

Toda función tiene la misma estructura: signo igual + nombre + paréntesis + argumentos separados por ; o ,.

= SUMA ( A1:A10 )
Signo = Nombre Parént. Argumento
0.2

Referencias relativas, absolutas y mixtas

⏱️ 15 min

Al copiar una fórmula, Excel puede fijar o cambiar columnas y filas. La tecla F4 cicla entre las 4 combinaciones.

A1

Relativa: cambia al copiar

0.3

Referencias a hojas y libros

⏱️ 15 min

El operador ! conecta una hoja con una celda. Los corchetes [ ] indican un libro externo.

// misma hoja:
=A1+B1
// otra hoja del libro:
=Hoja2!A1
// libro externo:
='[Otro.xlsx]Hoja1'!A1
0.4

Operadores de Excel

⏱️ 15 min

Los operadores se evalúan con una jerarquía: ^ → * / → + - → & → comparación. Usa paréntesis para forzar el orden.

Arit. + - * / ^ % → 5+3, 10/2, 2^3
Compar. = > < >= <= <> → A1>10
Texto & → "Hola"&" mundo"
Referencia : espacio , → A1:C5

0.6

Errores comunes y cómo corregirlos

⏱️ 15 min

Cada error tiene un código único. Reconocerlo es el primer paso para corregirlo.

Error Significado
#¡VALOR!Tipo de dato incorrecto (texto en operación numérica)
#N/AValor no disponible (BUSCARV no encuentra)
#REF!Referencia rota (celda eliminada)
#DIV/0!División entre cero
#¡NOMBRE?Función mal escrita (SUAM en vez de SUMA)
#¡NUM!Número inválido (raíz de negativo)
0.7

Anidar funciones correctamente

⏱️ 15 min

Anidar es usar el resultado de una función como argumento de otra. Cada paréntesis debe abrir y cerrar correctamente. Cuenta los pares: si abres 3, debes cerrar 3.

= SI ( Y ( A1>0 ; B1>0 ) ; "OK" ; "NO" )
Función exterior (SI) Función interior (Y) Resultados (texto)

Si A1 y B1 son positivos → "OK", si no → "NO"

2 Cómo moverte por la hoja

🖱️

Haz clic en una celda

para seleccionarla (se marca con un borde verde grueso).

⌨️

Usa las flechas del teclado

o Tab (derecha) y Enter (abajo).

🖐️

Arrastra con el ratón

para seleccionar un rango, por ejemplo A1:C5.

🔠

Clic en la letra de una columna

para seleccionarla completa (todas sus filas).

🔢

Clic en el número de una fila

para seleccionarla completa (todas sus celdas).

⏎

Enter para bajar

y confirmar la edición de la celda activa.

Sigue los pasos en tu Excel real (o en la interfaz de abajo).

  2. 2
